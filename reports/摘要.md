# 摘要

大模型智能体正在从内容生成系统演进为任务执行系统。随着 Agent 具备文件读写、接口调用、代码执行、消息发送和长期记忆等能力，风险已从模型输出延伸至工具调用、资源访问和外部动作执行过程。传统输入过滤和输出审查难以及时覆盖具有真实副作用的运行时行为，因此需要在动作执行前完成识别、判定、拦截、审批和留证。

**本作品设计并实现了 AgentGuard——智能体运行时行为监督审计系统。**系统不替代原有智能体框架或基础模型，而是**在智能体生成外部动作后、工具执行前加入独立监督环节**。Runtime Adapter 捕获工具调用、消息发送、上下文构建、模型输入输出、工具结果和记忆写入等事实，并将 LangGraph、OpenClaw 等环境中的原生行为转换为 GuardEvent 安全事件；Guard API / Control Plane 负责鉴权、策略加载、审计、审批、指标聚合和调用追踪；agentguard-core 依据策略规则、工具资源画像、上下文来源和检测结果生成 allow、deny、ask 三类决策。

**AgentGuard 采用“一核两壳”架构，将安全判定、运行时接入和状态管理解耦**，使检测、策略、审批、审计和评测能力跨运行时复用。系统覆盖敏感资源访问、工具调用劫持、任务不一致、数据外发、危险代码执行、提示注入和记忆污染等场景。其判定结合工具能力、资源类型、数据方向、用户任务和上下文可信度，实现风险放行、阻断与边界确认。

AgentGuard 覆盖敏感资源访问、工具调用劫持、任务不一致、数据外发、凭证暴露、危险代码执行、提示注入、越狱泄露、记忆污染和环境/工具结果污染等场景。**系统并非单纯依赖关键词拦截，而是结合工具能力、资源类型、数据方向、用户任务和上下文可信度进行综合判断。**对于需要复核的风险事件，平台通过 Dashboard 展示工具名称、调用参数、目标资源、命中规则、风险原因和上下文摘要，并提供仅作用于本次请求的人工审批能力。同时，系统通过审计记录、trace 追踪、审计哈希链和溯源图谱保留判定依据，使安全处置过程可解释、可追踪、可复核。

总体而言，系统将智能体安全从文本审核推进到运行时行为治理，形成判定、控制、审批、审计和评测分析的工程化闭环。
