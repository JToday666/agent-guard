# 威胁模型

## 1. 保护目标

AgentGuard 保护大模型 Agent 的运行时高风险行为：

- 工具调用；
- 文件读写；
- API 调用；
- 邮件或消息外发；
- 代码执行；
- 记忆写入；
- 上下文拼接；
- 工具结果回流；
- 最终输出。

## 2. 攻击面

| 攻击面 | 示例 |
|---|---|
| 提示注入 | 恶意邮件、文档、网页要求模型忽略规则 |
| 模型越狱 | 角色扮演、指令覆盖、多轮诱导 |
| 工具调用劫持 | 诱导调用非任务所需工具 |
| 文件泄露 | 读取 `.env`、token、secret |
| API 滥用 | 上传敏感数据、SSRF、越权调用 |
| 代码执行滥用 | 执行 shell、读取环境变量 |
| 记忆中毒 | 写入恶意长期规则 |
| 环境感知污染 | README、日志、API 返回污染 |
| 工具结果污染 | 工具返回结果中夹带指令 |
| 外发泄露 | 邮件、消息、API 上传敏感数据 |

## 3. 攻击链示例

```text
恶意邮件
→ 拼入上下文
→ 模型生成 read_file('/private/token.txt')
→ 工具调用被拦截
→ Core 判断来源不可信 + 敏感文件 + 任务不一致
→ deny
→ Dashboard 展示攻击链
```

## 4. 非目标

不承诺覆盖：

- 绕过框架的宿主机级文件访问；
- 恶意 OS 进程；
- 完整沙箱逃逸检测；
- 生产级多租户隔离。
