# 11. 最终原则

后续 PR Review 应不断追问：

```text
这段代码在产生“事实”？
还是在产生“决策”？
还是在产生“执行证据”？
```

如果一个 Context/Taint 模块同时做三件事，通常说明职责边界已经失控。
