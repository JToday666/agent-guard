# AgentGuard 统一鉴权管理方案

## 1. 核心原则

AgentGuard P0 采用本地 Capability Auth，不做用户登录，不做 Dashboard 解锁。

系统只有一个本机用户边界，鉴权目标是区分合法组件、合法 Dashboard 会话和未知请求。

P0 调用方分为三类：

```text
CLI / Launcher
Adapter / Plugin
Vue Dashboard
```

对应凭证：

```text
control token
adapter token
browser session
```

审批操作额外使用：

```text
approval nonce
```

所有鉴权结果统一转换为 `AuthContext`，业务接口只依赖 `AuthContext` 与 scope 校验。

## 2. 调用方与凭证

| 调用方           | 凭证            | 传递方式                | 用途                                     |
| ---------------- | --------------- | ----------------------- | ---------------------------------------- |
| CLI / Launcher   | control token   | `Authorization: Bearer` | 创建 launch code                         |
| Adapter / Plugin | adapter token   | `Authorization: Bearer` | 上报事件、请求安全判断、写审计、等待审批 |
| Vue Dashboard    | browser session | HttpOnly Cookie         | 访问 Dashboard API                       |
| Vue 状态改变请求 | CSRF token      | `X-AgentGuard-CSRF`     | 防跨站状态改变                           |
| 审批 resolve     | approval nonce  | JSON body               | 防审批重放和误放行                       |

长期凭证：

```text
control token
adapter token
```

短期凭证：

```text
launch code
browser session
CSRF token
approval nonce
```

长期凭证不进入浏览器。短期凭证默认放内存，短 TTL，过期或使用后失效。

## 3. 角色与 Scope

P0 角色：

| 角色        | 使用方                              | scopes                                                                                             |
| ----------- | ----------------------------------- | -------------------------------------------------------------------------------------------------- |
| `control`   | CLI / Launcher                      | `auth:launch`                                                                                      |
| `adapter`   | LangGraph Adapter / OpenClaw Plugin | `event:evaluate`, `event:audit:write`, `approval:wait`                                             |
| `dashboard` | Vue browser session                 | `audit:read`, `trace:read`, `metrics:read`, `provenance:read`, `approval:read`, `approval:resolve` |

禁止把以下权限授予 `adapter`：

```text
approval:resolve
audit:read
trace:read
metrics:read
provenance:read
policy:write
config:write
token:manage
system:admin
auth:launch
```

禁止把以下权限授予 `control`：

```text
approval:resolve
event:evaluate
event:audit:write
audit:read
metrics:read
policy:write
config:write
token:manage
```

## 4. 接口鉴权矩阵

### 公开接口

| 接口           | 鉴权   |
| -------------- | ------ |
| `GET /health`  | 不需要 |
| `GET /version` | 不需要 |
| `GET /ui/*`    | 不需要 |

### Browser Auth 接口

| 接口                             | 鉴权                                |
| -------------------------------- | ----------------------------------- |
| `POST /v1/auth/browser/launch`   | `auth:launch`，Bearer control token |
| `POST /v1/auth/browser/exchange` | launch code + Host / Origin 校验    |
| `GET /v1/auth/browser/me`        | browser session                     |
| `POST /v1/auth/browser/logout`   | browser session + CSRF              |

### Adapter 接口

| 接口                              | 权限                |
| --------------------------------- | ------------------- |
| `POST /v1/evaluate/context-build` | `event:evaluate`    |
| `POST /v1/evaluate/model-call`    | `event:evaluate`    |
| `POST /v1/evaluate/tool-call`     | `event:evaluate`    |
| `POST /v1/evaluate/tool-result`   | `event:evaluate`    |
| `POST /v1/evaluate/memory-write`  | `event:evaluate`    |
| `POST /v1/evaluate/message`       | `event:evaluate`    |
| `POST /v1/audit/event`            | `event:audit:write` |
| `GET /v1/approvals/{id}/wait`     | `approval:wait`     |

### Dashboard 接口

| 接口                              | 权限                                       |
| --------------------------------- | ------------------------------------------ |
| `GET /v1/audit/events`            | `audit:read`                               |
| `GET /v1/audit/traces/{trace_id}` | `trace:read`                               |
| `GET /v1/provenance/{trace_id}`   | `provenance:read`                          |
| `GET /v1/metrics/*`               | `metrics:read`                             |
| `GET /v1/approvals/pending`       | `approval:read`                            |
| `POST /v1/approvals/{id}/resolve` | `approval:resolve` + CSRF + approval nonce |

## 5. AuthContext

所有认证方式统一生成 `AuthContext`：

```python
AuthContext(
    principal_type="component | browser | cli",
    principal_id="cred_adapter_main | sess_xxx | cred_control",
    role="adapter | dashboard | control",
    scopes=["..."],
    auth_method="bearer | browser_session",
    runtime=None,
    agent_id=None,
)
```

业务接口不得直接读取 token、cookie 或 launch code。业务接口只使用：

```text
AuthContext
require_scope()
CSRF 校验结果
approval nonce 校验结果
```

## 6. 长期凭证生成

初始化命令：

```bash
agentguard init
```

生成：

```text
AGENTGUARD_CONTROL_TOKEN=ag_control_xxx
AGENTGUARD_ADAPTER_TOKEN=ag_adapter_xxx
```

保存位置：

```text
~/.agentguard/control.env
~/.agentguard/adapter.env
```

权限：

```bash
chmod 700 ~/.agentguard
chmod 600 ~/.agentguard/control.env
chmod 600 ~/.agentguard/adapter.env
```

明文 token 只在生成时展示一次，并写入本机私有配置文件。不得写入 Git、前端 env、日志或审计事件。

## 7. 长期凭证存储

Core 数据库只保存：

```text
credential_lookup_hash = HMAC-SHA256(core_secret, raw_token)
```

长期凭证表：

```sql
CREATE TABLE auth_credentials (
  credential_id TEXT PRIMARY KEY,
  credential_lookup_hash TEXT NOT NULL UNIQUE,
  role TEXT NOT NULL,
  scopes_json TEXT NOT NULL,
  runtime TEXT,
  agent_id TEXT,
  created_at TEXT NOT NULL,
  expires_at TEXT,
  revoked_at TEXT,
  last_used_at TEXT,
  record_mac TEXT NOT NULL
);
```

`credential_lookup_hash` 用于查找凭证。

`record_mac` 用于发现数据库字段被篡改：

```text
record_mac = HMAC-SHA256(core_secret, canonical_record_fields)
```

`record_mac` 覆盖字段：

```text
credential_id
credential_lookup_hash
role
scopes_json
runtime
agent_id
created_at
expires_at
revoked_at
```

`last_used_at` 不参与 `record_mac`，只作为观测字段。

`core_secret` 保存位置：

```text
~/.agentguard/secrets/core_secret
```

权限：

```bash
chmod 700 ~/.agentguard/secrets
chmod 600 ~/.agentguard/secrets/core_secret
```

`core_secret` 不存入数据库。

## 8. Bearer Token 验证

适用于：

```text
control token
adapter token
```

验证流程：

```text
1. 读取 Authorization header
2. 提取 Bearer token
3. 计算 credential_lookup_hash = HMAC-SHA256(core_secret, raw_token)
4. 查询 auth_credentials
5. 检查凭证存在
6. 检查 revoked_at 为空
7. 检查 expires_at 未过期
8. 校验 record_mac
9. 生成 AuthContext
10. 检查接口所需 scope
11. 更新 last_used_at
```

比较派生值时使用 constant-time compare。

## 9. Launch Code

`launch code` 只用于创建 browser session。

生成接口：

```http
POST /v1/auth/browser/launch
Authorization: Bearer <AGENTGUARD_CONTROL_TOKEN>
```

要求：

```text
control token 有效
scope 包含 auth:launch
Host 合法
如果请求包含 Origin，则 Origin 必须在允许列表内
```

响应：

```json
{
  "launch_code": "lc_xxx",
  "expires_in": 300
}
```

存储规则：

```text
只存内存
只存 HMAC 派生值
TTL 1-5 分钟
单次使用
Core 重启后全部失效
```

Vue exchange：

```http
POST /v1/auth/browser/exchange
Content-Type: application/json

{
  "launch_code": "lc_xxx"
}
```

exchange 成功后：

```text
创建 browser session
设置 HttpOnly Cookie
返回 csrf_token 和 expires_at
立即失效 launch code
```

## 10. Browser Session

Browser session 只给 Vue Dashboard 使用。

Cookie：

```http
Set-Cookie: agentguard_session=sess_xxx; HttpOnly; SameSite=Strict; Path=/v1; Max-Age=3600
```

服务端存储：

```text
只存内存
存 session_lookup_hash
绑定 role=dashboard
绑定 dashboard scopes
绑定 csrf_lookup_hash
保存 created_at、expires_at、revoked_at
Core 重启后失效
```

Dashboard scopes：

```text
audit:read
trace:read
metrics:read
provenance:read
approval:read
approval:resolve
```

`/v1/auth/browser/me`：

```text
只接受有效 browser session cookie
不接受 Bearer token
不创建新 session
默认不延长 session
返回 authenticated、expires_at、csrf_token
```

`/v1/auth/browser/logout`：

```text
要求 browser session + CSRF
撤销 session
清除 cookie
```

## 11. CSRF

CSRF 只适用于 browser session 鉴权的状态改变请求。

需要 CSRF 的方法：

```text
POST
PUT
PATCH
DELETE
```

Header：

```http
X-AgentGuard-CSRF: csrf_xxx
```

CSRF token：

```text
由 Core 生成
随 exchange 或 /me 返回
Vue 只存在 Pinia 内存
服务端只存 HMAC 派生值
随 session 失效
```

Adapter 和 CLI 使用 Bearer token，不使用 CSRF。

## 12. Approval Nonce

Approval nonce 只用于审批 resolve。

生成时机：

```text
Dashboard 调用 GET /v1/approvals/pending 时生成或返回
```

绑定字段：

```text
approval_id
session_hash
tool_call_id
decision_options
expires_at
```

提交审批：

```http
POST /v1/approvals/app_123/resolve
Cookie: agentguard_session=sess_xxx
X-AgentGuard-CSRF: csrf_xxx
Content-Type: application/json

{
  "decision": "allow_once",
  "approval_nonce": "nonce_xxx"
}
```

Core 校验：

```text
browser session 有效
scope 包含 approval:resolve
CSRF 正确
approval_id 存在
approval status = pending
approval 未过期
decision 属于允许选项
approval_nonce 属于当前 session
approval_nonce 属于当前 approval
approval_nonce 属于当前 tool_call_id
approval_nonce 未使用
```

成功后：

```text
先消费 approval nonce
再更新 approval 状态
allow_once 只绑定当前 tool_call_id
```

## 13. Approval Wait

Adapter 只能等待自身关联 approval。

Core 创建 approval 时记录：

```text
approval_id
requesting_principal_id
trace_id
tool_call_id
runtime
agent_id
created_at
expires_at
status
```

Adapter wait 校验：

```text
auth.role = adapter
auth.scopes 包含 approval:wait
approval.requesting_principal_id = auth.principal_id
approval 属于该 Adapter 创建或关联的 tool_call
```

Adapter 不能：

```text
列出 pending approval
读取无关 approval
resolve approval
```

## 14. Host 与 Origin 校验

Core 默认只绑定：

```text
127.0.0.1:8088
```

允许 Host：

```text
127.0.0.1:8088
localhost:8088
```

开发环境如果使用其他端口或 WSL 转发地址，必须显式配置 allowlist。

Core 所有 API 请求都必须校验 Host。带 Origin 的浏览器请求必须校验 Origin，browser session 模式下的状态改变请求必须额外校验 CSRF。

需要重点校验的接口：

```text
POST /v1/auth/browser/launch
POST /v1/auth/browser/exchange
POST /v1/auth/browser/logout
POST /v1/approvals/{id}/resolve
所有 browser session 模式下的 POST / PUT / PATCH / DELETE
```

## 15. CORS

生产模式推荐同源部署，不启用跨域。

开发模式允许：

```text
Access-Control-Allow-Credentials: true
Access-Control-Allow-Origin: http://127.0.0.1:5173
Access-Control-Allow-Headers: Content-Type, X-AgentGuard-CSRF, Authorization
Access-Control-Allow-Methods: GET, POST, PUT, PATCH, DELETE, OPTIONS
```

禁止：

```text
Access-Control-Allow-Origin: *
```

当允许携带凭证时，`Access-Control-Allow-Origin` 必须是明确 Origin。

## 16. 凭证销毁与重置

短期凭证销毁：

| 凭证            | 销毁条件                                       |
| --------------- | ---------------------------------------------- |
| launch code     | exchange 成功、过期、Core 重启                 |
| browser session | logout、过期、Core 重启                        |
| CSRF token      | session 失效                                   |
| approval nonce  | 使用后、approval 超时、session 失效、Core 重启 |

长期凭证重置：

```bash
agentguard auth reset
```

执行效果：

```text
撤销旧 control token
撤销旧 adapter token
重新生成 control token
重新生成 adapter token
重写 ~/.agentguard/control.env
重写 ~/.agentguard/adapter.env
清空所有 launch code、browser session、approval nonce
写入审计记录
```

P0 不需要 token 管理 UI。

## 17. 错误码

| 场景                | 状态码 | 错误码                      |
| ------------------- | ------ | --------------------------- |
| 缺少认证            | `401`  | `AUTH_MISSING`              |
| token 无效          | `401`  | `TOKEN_INVALID`             |
| token 撤销          | `401`  | `TOKEN_REVOKED`             |
| token 过期          | `401`  | `TOKEN_EXPIRED`             |
| session 无效        | `401`  | `SESSION_INVALID`           |
| session 过期        | `401`  | `SESSION_EXPIRED`           |
| launch code 无效    | `401`  | `LAUNCH_CODE_INVALID`       |
| launch code 过期    | `401`  | `LAUNCH_CODE_EXPIRED`       |
| scope 不足          | `403`  | `SCOPE_DENIED`              |
| CSRF 失败           | `403`  | `CSRF_INVALID`              |
| Origin 不允许       | `403`  | `ORIGIN_DENIED`             |
| Host 不允许         | `403`  | `HOST_DENIED`               |
| approval nonce 无效 | `403`  | `APPROVAL_NONCE_INVALID`    |
| 等待无关 approval   | `403`  | `APPROVAL_WAIT_DENIED`      |
| approval 已处理     | `409`  | `APPROVAL_ALREADY_RESOLVED` |
| approval 已过期     | `409`  | `APPROVAL_EXPIRED`          |

## 18. 审计要求

所有鉴权失败必须记录审计事件，但不得记录完整敏感凭证。

允许记录：

```text
principal_type
principal_id
role
auth_method
request_path
auth_result
error_code
runtime
agent_id
token_id 或 credential_id
session hash 摘要
```

禁止记录完整：

```text
Authorization header
raw token
launch code
session id
CSRF token
approval nonce
Cookie
敏感请求字段
```

审计记录示例：

```json
{
  "principal_type": "component",
  "principal_id": "cred_adapter_main",
  "role": "adapter",
  "auth_method": "bearer",
  "request_path": "/v1/evaluate/tool-call",
  "auth_result": "allowed"
}
```

## 19. P0 实施清单

```text
实现 AuthService
实现 AuthContext
实现 require_scope()
实现 auth_credentials 表
实现 credential_lookup_hash
实现 record_mac
agentguard init 生成 control token 和 adapter token
agentguard auth reset 重置本地凭证
实现 verify_bearer_token()
实现 launch code 内存 store
实现 browser session 内存 store
实现 CSRF 校验
实现 approval nonce 内存 store
实现 approval wait 归属校验
Vue exchange 后使用 browser session
Adapter API 使用 adapter token
CLI / Launcher 使用 control token
所有业务接口接入 scope 校验
所有鉴权失败写审计
禁止完整凭证进入日志
Core 默认监听 127.0.0.1:8088
开发模式配置 CORS allowlist
```

## 20. P0 不做

```text
用户登录
Dashboard 解锁
用户注册
找回密码
多租户
复杂 RBAC 页面
OAuth
SSO
JWT
mTLS
每个请求签名
动态适配器注册
远程适配器接入
token 管理 UI
每个 runtime 默认独立 token
每个 agent 默认独立 token
```

## 21. P1 扩展方向

P1 扩展不得推翻 P0 的 `AuthContext + scope` 模型。

可扩展项：

```text
每个 runtime + agent_id 独立 adapter token
token rotate / revoke CLI
更细粒度 adapter scopes
Dashboard token 管理页面
多 browser session 管理
审批通道 token
远程访问时启用 HTTPS 和更强认证
```
