# AgentGuard Adapter 鉴权方案

## 1. 核心原则

P0 只使用一个 adapter token：

```text
AGENTGUARD_ADAPTER_TOKEN
```

该 token 给 LangGraph Adapter / OpenClaw Plugin 使用，只允许：

```text
上报运行时事件
请求 Core 做安全判断
写入审计事件
等待自身关联 approval 的处理结果
```

Adapter 不能批准自己的高危请求，不能读取 Dashboard 数据，不能修改策略，不能管理 token，不能生成 browser session。

Adapter 不使用：

```text
browser session
CSRF token
launch code
approval nonce
```

Adapter 只使用：

```http
Authorization: Bearer <AGENTGUARD_ADAPTER_TOKEN>
```

## 2. Adapter Token 初始化

初始化命令：

```bash
agentguard init
```

生成本地配置文件：

```text
~/.agentguard/adapter.env
```

内容：

```env
AGENTGUARD_CORE_URL=http://127.0.0.1:8088
AGENTGUARD_ADAPTER_TOKEN=ag_adapter_xxx
AGENTGUARD_AGENT_ID=main
AGENTGUARD_RUNTIME=langgraph
```

文件权限：

```bash
chmod 600 ~/.agentguard/adapter.env
```

`.env` 或本地配置文件不得提交到 Git。

Core 数据库不保存明文 token，只保存：

```text
credential_lookup_hash = HMAC-SHA256(core_secret, raw_token)
```

## 3. Adapter Scopes

P0 adapter scopes：

```text
event:evaluate
event:audit:write
approval:wait
```

允许行为：

| 权限                | 允许行为                                    |
| ------------------- | ------------------------------------------- |
| `event:evaluate`    | 调用 `/v1/evaluate/*`，请求 Core 做风险判断 |
| `event:audit:write` | 调用 `/v1/audit/event`，写入审计事件        |
| `approval:wait`     | 等待自身关联 approval 的处理结果            |

禁止授予 adapter：

```text
approval:resolve
audit:read
trace:read
metrics:read
provenance:read
policy:read
policy:write
config:read
config:write
token:manage
system:admin
auth:launch
```

`approval:resolve` 不得授予 adapter。否则 Adapter 可以批准自己的高危工具调用，审批链路失效。

## 4. Adapter 请求方式

请求示例：

```http
POST /v1/evaluate/tool-call
Authorization: Bearer ag_adapter_xxx
Content-Type: application/json
```

请求体示例：

```json
{
  "schema_version": "0.3",
  "event_type": "tool_call_proposed",
  "runtime": "langgraph",
  "trace_id": "trace_001",
  "agent_id": "main",
  "tool": {
    "name": "read_file",
    "kind": "file_read"
  },
  "arguments": {
    "path": "/private/token.txt"
  }
}
```

P0 中 `runtime` 与 `agent_id` 主要用于审计和排查。Core 不把它们作为强隔离边界。

## 5. Adapter API 权限

| 接口                              | 权限                |
| --------------------------------- | ------------------- |
| `POST /v1/evaluate/context-build` | `event:evaluate`    |
| `POST /v1/evaluate/model-call`    | `event:evaluate`    |
| `POST /v1/evaluate/tool-call`     | `event:evaluate`    |
| `POST /v1/evaluate/tool-result`   | `event:evaluate`    |
| `POST /v1/evaluate/memory-write`  | `event:evaluate`    |
| `POST /v1/evaluate/message`       | `event:evaluate`    |
| `POST /v1/audit/event`            | `event:audit:write` |
| `GET /v1/approvals/{id}/wait`     | `approval:wait`     |

`GET /v1/approvals/{id}/wait` 只能等待当前 Adapter 请求关联的 approval，不能枚举全部 pending approval。

## 6. Core 校验流程

Bearer token 校验流程：

```text
1. 读取 Authorization header
2. 提取 Bearer token
3. 计算 credential_lookup_hash = HMAC-SHA256(core_secret, raw_token)
4. 查询 auth_credentials
5. 检查凭证存在
6. 检查 revoked_at 为空
7. 检查 expires_at 未过期
8. 校验 record_mac
9. 生成 AuthContext
10. 检查接口需要的 scope
11. 更新 last_used_at
12. 进入业务逻辑
```

比较 token 派生值时使用 constant-time compare。

`AuthContext`：

```python
AuthContext(
    principal_type="component",
    principal_id="cred_adapter_main",
    role="adapter",
    scopes=["event:evaluate", "event:audit:write", "approval:wait"],
    auth_method="bearer",
    agent_id="main",
    runtime="langgraph",
)
```

业务接口只依赖 `AuthContext` 和 scope，不直接解析 token。

## 7. Runtime 与 Agent ID

P0：adapter token 只区分“合法 Adapter”与“非法请求”，不强隔离 LangGraph / OpenClaw。`runtime` 与 `agent_id` 仅作为审计字段。

默认值：

```text
runtime = langgraph
agent_id = main
```

同一 P0 环境同时接入 OpenClaw Plugin 时，可共用同一个 adapter token，并在请求体或 Adapter 配置中记录 runtime 来源。该来源只用于审计和排查，不作为强隔离边界。

P1：每个 `runtime + agent_id` 使用独立 adapter token：

```text
tok_adapter_langgraph_main
tok_adapter_openclaw_main
tok_adapter_langgraph_eval_agent_001
```

P1 扩展不得改变业务接口的 scope 校验方式，只扩展 `AuthContext` 中的 `runtime` 与 `agent_id` 绑定规则。

## 8. Approval Wait

Core 创建 approval 时必须记录：

```text
approval_id
requesting_principal_id
trace_id
tool_call_id
agent_id
runtime
created_at
expires_at
status
```

Adapter 调用：

```http
GET /v1/approvals/app_123/wait
Authorization: Bearer ag_adapter_xxx
```

Core 必须校验：

```text
auth.role = adapter
auth.scopes 包含 approval:wait
approval_id 存在
approval.requesting_principal_id = auth.principal_id
approval 属于该 Adapter 创建或关联的 tool_call
approval 未被删除
```

返回示例：

```json
{
  "status": "resolved",
  "decision": "allow_once"
}
```

超时示例：

```json
{
  "status": "timeout",
  "decision": "deny"
}
```

Adapter 不能通过 `approval:wait` 获取 pending approval 列表，也不能等待无关 approval。

## 9. 长期凭证存储

长期凭证表：

```sql
CREATE TABLE auth_credentials (
  credential_id TEXT PRIMARY KEY,
  credential_lookup_hash TEXT NOT NULL UNIQUE,
  role TEXT NOT NULL,
  scopes_json TEXT NOT NULL,
  runtime TEXT,
  agent_id TEXT,
  created_at TEXT NOT NULL,
  expires_at TEXT,
  revoked_at TEXT,
  last_used_at TEXT,
  record_mac TEXT NOT NULL
);
```

adapter 记录示例：

```json
{
  "credential_id": "cred_adapter_main",
  "role": "adapter",
  "scopes": ["event:evaluate", "event:audit:write", "approval:wait"],
  "runtime": "langgraph",
  "agent_id": "main"
}
```

`record_mac` 计算字段：

```text
credential_id
credential_lookup_hash
role
scopes_json
runtime
agent_id
created_at
expires_at
revoked_at
```

`last_used_at` 不参与 `record_mac`，只作为观测字段。

`record_mac`：

```text
HMAC-SHA256(core_secret, canonical_record_fields)
```

## 10. 安全底线

Core 默认只绑定：

```text
127.0.0.1:8088
```

Adapter token 泄露后的影响必须限制在：

```text
伪造事件评估请求
伪造审计写入
等待自身已知 approval 的结果
```

Adapter token 泄露后不得能够：

```text
批准审批
读取 Dashboard 数据
读取策略或配置
修改策略或配置
生成 browser session
管理 token
```

禁止在日志、数据库、审计事件中记录完整：

```text
Authorization header
adapter token
launch code
approval nonce
CSRF token
Cookie
```

## 11. 错误处理

未提供 token：

```text
401 AUTH_MISSING
```

token 无效：

```text
401 TOKEN_INVALID
```

token 已撤销：

```text
401 TOKEN_REVOKED
```

token 已过期：

```text
401 TOKEN_EXPIRED
```

scope 不足：

```text
403 SCOPE_DENIED
```

等待无关 approval：

```text
403 APPROVAL_WAIT_DENIED
```

approval 已处理：

```text
409 APPROVAL_ALREADY_RESOLVED
```

approval 已过期：

```text
409 APPROVAL_EXPIRED
```

## 12. 审计字段

Adapter 请求审计记录：

```json
{
  "principal_type": "component",
  "principal_id": "cred_adapter_main",
  "role": "adapter",
  "auth_method": "bearer",
  "runtime": "langgraph",
  "agent_id": "main",
  "request_path": "/v1/evaluate/tool-call",
  "auth_result": "allowed"
}
```

鉴权失败审计记录：

```json
{
  "principal_type": "unknown",
  "auth_method": "bearer",
  "request_path": "/v1/evaluate/tool-call",
  "auth_result": "denied",
  "reason": "TOKEN_INVALID"
}
```

## 13. P0 实施清单

```text
agentguard init 生成 AGENTGUARD_ADAPTER_TOKEN
写入 ~/.agentguard/adapter.env
Core auth_credentials 只保存 credential_lookup_hash
实现 verify_bearer_token()
verify_bearer_token() 生成 AuthContext
Adapter API 使用 require_scope()
event API 要求 event:evaluate
audit 写入要求 event:audit:write
approval wait 要求 approval:wait
approval wait 只能等待当前请求关联 approval
adapter token 不授予 approval:resolve
鉴权失败写审计
更新 last_used_at
实现 agentguard auth reset 以重置本地凭证
```

## 14. P0 不做

```text
适配器登录
动态适配器注册
每个请求签名
每个 agent 默认独立 token
每个 runtime 默认独立 token
远程适配器接入
复杂外部认证协议
适配器 token 管理 UI
mTLS
OAuth
JWT
```
